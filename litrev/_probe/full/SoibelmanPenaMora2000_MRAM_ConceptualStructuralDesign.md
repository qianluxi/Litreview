# SoibelmanPenaMora2000_MRAM_ConceptualStructuralDesign

- 抽取范围：全文 1–10 页

## 1. 一句话主张
- 论断：作者提出 M-RAM（多推理模型），通过分布式多推理机制向设计者提供经适应的既有设计方案，以辅助高层建筑结构设计的概念阶段。
- 引文："This paper presents the M-RAM, which is intended to assist engineers in the conceptual phase of the structural design of tall buildings by providing designers with adapted past design solutions generated by a distributed multi-reasoning mechanism." (Soibelman et al., 2000, p.1)

## 2. 问题域
- 论断：问题域是结构设计的概念阶段，涉及初选材料、选择建筑整体结构形式、生成粗略尺寸布置并考虑技术可能性。
- 引文："The conceptual phase of structural design involves selecting preliminary materials, selecting the overall structural form of the building, producing a rough dimensional layout, and considering technological possibilities." (Soibelman et al., 2000, p.1)

## 3. 案例或数据的表示形式
- 论断：案例以描述该案例的 19 个属性的取值来表示，这些取值构成案例描述，并被定义为案例表型。
- 引文："The values that are associated with each of the 19 attributes in the description of a case make up the case description and can be deﬁned as the case phenotype (Fig. 3)." (Soibelman et al., 2000, p.6)

## 4. 相似性或检索机制
- 论断：检索由 Caspian 执行，索引检索完成后可运行两种模式，启用案例匹配器时程序扫描案例子集并找出权重值最高的案例。
- 引文："After the index search has been completely successfully, Caspian can be run in two different modes: with or without case matcher. If the case matcher is invoked, the program scans the subset of cases to ﬁnd the one with the highest weight value." (Soibelman et al., 2000, p.5)

## 5. 系统形态
- 论断：系统形态是实际实现的 M-RAM，由用 Java 编写的 WWW 界面接收输入并启动 manager 程序。
- 引文："In the actual M-RAM implementation, a WWW interface written in Java (e.g., ﬁrst tier) receives the expected data as input and launches the manager program (e.g., second tier)." (Soibelman et al., 2000, p.7)

## 6. 评价方式
- 论断：评价方式是开发原型并以一个假设的波士顿办公楼设计为例，展示原型如何运行及其设计建议，以检验模型的可行性。
- 引文："To test the feasibility of the proposed model, an M-RAM prototype was developed. To see how the prototype works and its design recommendations, consider, for example, the design of a hypothetical ofﬁce building in Boston, Massachusetts." (Soibelman et al., 2000, p.7)

## 7. 明确写出的局限
- 论断：作者明确指出这些数据不足以归纳出好的泛化。
- 引文："We recognize the fact that these data are not sufﬁcient to induce a good generalization." (Soibelman et al., 2000, p.4)
