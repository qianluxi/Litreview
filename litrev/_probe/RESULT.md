# 微缩引文抽取测试 — 结果

测试日期：2026-11-09
目的：在正式做文献综述之前，用 1/7 规模的任务测这套 subagent 编排的真实可用性。
**注意：本次由 WorkBuddy 主控 + 3 个并行 subagent 执行，不是 OpenCode 原生 `task`。**（原生机制已在 `Opencode_Subagent` 项目中单独验证）

## 一、设计

| 项 | 内容 |
| --- | --- |
| 输入 | 3 篇 8 页文献，由主控统一导出为带 `<<<PAGE n>>>` 标记的纯文本 |
| 任务 | 每篇抽 3 条直接引文，各条指定命题（第 3 条刻意选"偏门"项） |
| 契约 | `_probe/CONTRACT.md`，包含格式、逐字要求、≥20 字母下限、不跨页、禁止多余双引号 |
| 隔离 | 一 agent 一篇，一文件一输出，互不通信；**禁止运行核验工具** |
| 裁判 | `litrev.py verify`，主控执行 |
| 反向题 | 另派 1 个 agent 抽"Napps2021 的实验数据集规模"与"检索准确率"——该项经 grep 确认不存在 |

## 二、结果

### 正向：9/9 PASS

| 文献 | 结果 |
| --- | --- |
| Napps2021 | 3/3 PASS |
| Ayzenshtadt2016 | 3/3 PASS |
| MaherGomez1997 | 3/3 PASS |

三条"偏门"命题全部命中，且都是原文：

- Napps2021 相似度计算的依据 → `similarities are used for all entities stored in the IFC data structure`（p.3）
- Ayzenshtadt2016 agent 的组织方式 → `a container-based structure ... nested inside a parent MAS`（p.5）
- MaherGomez1997 indexing 的具体动作 → `Indexing identifies the features a previous design should have to be relevant to the new design problem`（p.2）

### 反向：4/4 PASS，但**一条都没回答问题**

派出去的命题是"实验数据集规模"和"检索准确率"。agent 没有编造，而是：

- 明确写出 `NOT_FOUND：全文 1–8 页都没有以数字给出的数据集规模`
- 主动识别 `0% / <5% / 5%–10%` 是**偏差分档表**，不是准确率
- 主动指出 `0,694` / `0,86` 是加权相似度得分，不是实验指标

它引用的 4 条句子全部真实存在，verify 给 4/4 PASS。**但这份笔记完全没有回答提出的问题。**

## 三、verify 抓不到的三个问题

| # | 问题 | 实例 | 后果 |
| --- | --- | --- | --- |
| 1 | **引文真实但答非所问** | 反向测试 4/4 PASS，却零回答问题 | 用 verify 通过率验收综述，答非所问的稿子会 100% 通过 |
| 2 | **引文不自足** | MaherGomez 第 2 条 `it decomposes into the subtasks of...`，主语 `Design-case recall` 被截在引号外 | 逐字正确、页码正确，但读者不知道 `it` 指什么，学术上不可引用 |
| 3 | **论断可以略微超出引文** | Napps 第 3 条论断写"基于 IFC 标准"，引文只说到"IFC data structure" | 从"数据结构"推到"标准"是合理推断，但不是原文陈述 |

前两条是结构性的：`verify` 校验的是**引文层**，不是**论断层**。它能回答"这句话是不是原文"，不能回答"这句话是否支撑这个论点"。

## 四、本次测试没能覆盖的

1. **PDF 页码定位**：输入已带 `<<<PAGE n>>>` 标记，agent 只需照抄标记。若让它直接读 PDF 自行定页，难度完全不同。
2. **规模效应**：3 篇 vs 22 篇，上下文与协调成本未测。
3. **跨篇一致性**：三篇各抽 3 条互不相干，未测"同一字段在 22 篇间的口径统一"。
4. **权限隔离**：靠 prompt 约束"只写自己那一篇"，未用运行时权限强制。

## 五、结论

**能力层：可用。** 3 个 agent 并行、各自独立完成、产出格式高度一致（因为契约够具体），零冲突、零编造。给它干净文本和明确命题，精确抄录是可靠的。

**验收层：不够。** verify 只守住了"引文真伪"这一道。真正决定综述质量的是"引文是否支撑论断"，而这一层目前没有任何机械检查。22 篇并行跑下去，得到的会是一批**真实但零散**的引文，而不是论证——中间那一步（从引文到论断）必须由人或一个独立的判断层来做。

**下一步的前提条件**：在做全量之前，先补一个"论断-引文一致性"检查，否则规模越大，返工越贵。

## 六、产物位置

```
_probe/CONTRACT.md          测试契约
_probe/texts/*.txt          3 篇导出文本（带页标记）
_probe/notes/*.md           agent 产出（4 份，含反向测试）
_probe/notes/*_引文核验.md   verify 自动生成的核验报告
```

副作用提示：`verify` 会把核验报告写在源文件同目录，实际使用时 `notes/` 会被 `*_引文核验.md` 污染。

## 七、追加测试 A：不给导出文本，让 agent 自己从 PDF 定页

针对第四节的局限 1（页码靠照抄标记）补做。设计上加了页码陷阱：选两篇**印张页码与物理页不一致**的文献。

| 文献 | 物理页 | 印张偏移 | agent 报的页 |
| --- | --- | --- | --- |
| MaherGomez1996 | 11 | +41（期刊 42–51） | p.1 / p.2 |
| Rodrigues2017 | 18 | +47（期刊 48–65） | p.1 / p.2 |

**结果：4/4 PASS。**

两个 agent 都主动做了三件我没要求的事：

1. 用 `page_index + 1` 换算物理页，并明确声明报的不是期刊页码；
2. **自己算出偏移量**（41 与 47），MaherGomez 那个还逐页抓页脚文本块核对（物理 1→42、2→43……）；
3. 自己复核引文是否跨页、是否唯一命中。Rodrigues 那个还原了 `Euclidean dis-` 的行末断词。

### 陷阱有效性（变异验证）

把两份笔记的页码改成期刊页码（p.1→p.42、p.2→p.43 等）后重跑：

```
MaherGomez1996: PAGE=2   合计 2
Rodrigues2017 : PAGE=2   合计 2
```

全判 `PAGE`。**说明这次 4/4 不是"怎么报都过"，页码真的在被验。**

### A 的结论

技术层不是瓶颈：PDF 文本提取、物理页与期刊页的区分、行末断词还原，agent 都做对了，甚至主动加固。

但仍有两点局限：4 条引文全部取自第 1–2 页（图表少、定位容易），中后段跨栏密集区未测；`subagent_depth=1` 时这类自检能力不会向下传递。

**至此，瓶颈已经明确落在论断层，而不是技术层。** 下一步该做的是"引文是否支撑论断"的审计，不是继续加大规模。

## 八、追加测试 B：补论断层审计 + 标定（2026-11-09）

针对第三节的"验收层不够"，新增第 4 个角色 `auditor` 与一份独立契约 `AUDIT_CONTRACT.md`，并用两轮标定测它判得准不准。完整记录见 `_probe/AUDIT_RESULT.md`，记分卡见 `_probe/audit/SCORECARD_v1.md`。

### 结果摘要

| 项 | 结果 |
|---|---|
| 支撑轴与人工基准的吻合 | 审计员 A 11/13、B 11/13；**A 与 B 之间 13/13 完全相同** |
| 不一致的分布 | 恰好同两条（02、06），且同向偏严 → 口径问题，不是随机波动 |
| 变异检出率 | **5/5**：没有一条注入变异被放行为 SUPPORTED |
| 严重度精确率 | 3/5：该判 UNSUPPORTED 的有 2 条判成 PARTIAL |
| 对照稳定性 | 3/3 与第 1 轮一致 |

### 最关键的一条证据

第三节那四条"`verify` 给 4/4 PASS、却一条都没回答问题"的引文，在审计层里 A、B **全部判 `PARTIAL`**，理由一致指向：论断里的"没有给出 / 没有报告"是缺席命题，单条引文证明不了。

**同一批引文：`verify` 4/4 PASS，审计层 0/4 PASS。** 两层守的不是同一个东西，这一层补的位置是对的。

### 标定得到的口径修订

1. 自足轴只管主语，句首的指代性状语（`According to this approach` / `Using this formula`）不算 `DEPENDENT`。
2. 论断的核心对象或谓语被替换、或加了排他性最高级 → `UNSUPPORTED`；只加强限定词、只放大范围 → `PARTIAL`。
3. **判定码只能分诊**：`SUPPORTED` 可自动通过，非 `SUPPORTED` 必须人看。严重度会偏轻（2/5），拿它做自动拦截会漏。

### 这一层的边界（没有被它解决）

- 闭卷，断章取义看不见；
- 只测"引文 → 论断"，"论断 → 论证主线"仍只能由人判；
- 单模型、单标、n=21，换模型或换文献域都要重标。
