# 论断-引文一致性审计契约（v1.2，闭卷）

本文件是审计层的唯一判定标准。`litrev.py verify` 守的是引文层（这句是不是原文、页对不对），本层守的是**论断层**（这条引文是否撑得起这个论断）。两层互不替代。

## 一、输入（一条 = 五元组）

| 字段 | 含义 |
|---|---|
| `id` | 条目编号 |
| `论断` | 笔记里那句话（中文），即作者要读者相信的命题 |
| `引文` | 支持它的那句原文（引号内） |
| `页码` | 笔记标注的 PDF 物理页 |
| `出处` | 作者-年份 |

**闭卷**：只给引文本身，不给上下文。这是刻意的——本层测的是"读者只看这一句，能不能接受这个论断"。

## 二、两个轴，各自独立判

### 轴 1：支撑（引文对论断的支持度）

| 码 | 定义 |
|---|---|
| `SUPPORTED` | 论断的每个可检验成分（主体、动作、对象、范围、限定强度）都能在引文里找到对应表述，且没有添加原文没有的内容 |
| `PARTIAL` | 主干方向一致，但有成分无依据：限定词被加强、范围被放大、术语被替换，或混入了引文无法证明的成分 |
| `UNSUPPORTED` | 方向相反、彼此无关，或论断的主体/对象与引文不是同一个东西 |

### 轴 2：自足（引文脱离上下文能不能读）

| 码 | 定义 |
|---|---|
| `SELF` | 引文自带主语与指代，单看这一句就知道在说谁、说什么 |
| `DEPENDENT` | 引文以 `it / this / these / such` 开头，或主语落在引号外，单看不知道指代什么（**`this paper / this section` 这类篇章自指除外，见 §八**） |

`DEPENDENT` 可以同时是 `SUPPORTED`：论断写对了，但这条引文在学术写作里不可直接引用。

**三族边界见 §八**（v1.2）：`this paper/section` = 自指 → `SELF`；`this approach/these limitations` = 回指 → 看先行词在不在引文内。

## 三、五条判定规则（易错点，按此裁定）

1. **情态不得升级**：原文 `can be defined` / `may` / `in the presented example` 不得被写成"是 / 必然 / 普遍适用"。`can be` → "分别定义了" 属升级。
2. **范围不得放大**：一个案例、一个示例、某一步骤，不得写成"该方法 / 该文 / 普遍"。
3. **术语不得替换**：`data structure` ≠ `standard`；`similarity` ≠ `accuracy`；`retrieval` ≠ `classification`。近义词不等于原文。
4. **否定不能由单条引文证明**：`没有给出 / 未报告 / 全文均无` 属缺席命题，需要全库检索证据。条目里混入这类成分（哪怕其余部分有引文支撑）判 `PARTIAL`，并在"缺什么"里写明缺的是缺席证据。
5. **论断补主语不算越界**：引文是 `it decomposes into...`，论断写明 `设计案例召回分解为...`，支撑判 `SUPPORTED`，自足判 `DEPENDENT`。补主语是论断的职责，不是引文的。

## 四、输出格式（严格照抄，不要额外发挥）

**第一行必须是**：原样抄输入文件里的 `> 快照 sha1: <10 位>`，一个字符都不能改。
它是判定与所依据文字的绑定凭证；漏抄或抄错，`litrev.py audit-stale` 判为"来源不明"，整批作废重做。

> 批次输入文件里若还写着「输出：只输出表格 + 一行合计」，那是旧模板遗留，**以本节为准**：
> 戳行 + 表格 + 合计行。同理，表头以本节为准，不要用批次输入里那份简化表头。

**其后**：下表（表头一字不改）

```
| id | 支撑 | 自足 | 引文里的依据（≤15 字，必须是引文原词） | 缺什么 / 需补的一句 |
|----|------|------|--------------------------------------|--------------------|
| 01 | PARTIAL | SELF | "can be defined" | 删去"即基于 IFC 标准"，或补原文依据 |
```

表格行序与输入条目一致，末尾加一行：`合计：N 条（SUPPORTED x / PARTIAL y / UNSUPPORTED z；DEPENDENT w）`。
除戳行、表格、合计行外不写任何东西。

## 五、口径修订（v1 标定后追加，2026-11-09）

第一轮标定（13 条）+ 变异测试（8 条）暴露出两处定义歧义，按下列口径执行，覆盖上文相应表述：

1. **自足轴只管主语**。只有"主语缺失"或"代词作主语"（`it/this/these/such` + 谓语）才判 `DEPENDENT`。句首的指代性状语——`According to this approach`、`Using this formula`、`After these steps`、`In the presented example`——**不算**，因为主谓齐全，单看这一句能读懂。
2. **PARTIAL 与 UNSUPPORTED 的边界**看"换没换东西"：
   - 论断的核心**对象或谓语被替换**（`Semantic Fingerprint` → "BIM 标准"），或加了**排他性最高级**（唯一 / 所有 / 必然 / 均未）→ `UNSUPPORTED`；
   - 只是**加强限定词、放大范围**（`can be` → "是"，`we use` → "普遍"）→ `PARTIAL`。
3. **判定码只用于分诊，不用于自动拦截**：`SUPPORTED` 可自动通过；任何非 `SUPPORTED` 必须人看。实测严重度会偏轻——该判 UNSUPPORTED 的有 2/5 被判成 PARTIAL，但 **5/5 变异无一被放行为 SUPPORTED**。

   > **v1.1 更正（见 §七.2，优先于本条）**：本条「`SUPPORTED` 可自动通过」只描述**分诊时不必逐条人审**，
   > 不是质量放行；`SUPPORTED` 仍须按 10%–15% 抽检。这是同一规则的收紧说明，**不构成契约自相矛盾**，
   > 不要因此写 `CONTRACT_CONFLICT` 停机。

## 六、明确不做的事

- **不判论证质量**：这个缺口是否成立、这条主线是否站得住，不在本层范围。
- **不判引文真伪与页码**：那是 `verify` 的事，本层默认输入已通过 `verify`。
- **不看上下文**：引文是否被断章取义（原文下一句就是反驳），闭卷审计看不出来。这是本层的已知盲区，不要假装能判。
- **不给"建议改写"以外的动作**：本层只出判定，不改稿件。

## 七、v1.1 补充口径（2026-11-09 核验后）

以下两条只适用于后续复核/重审，不追溯改本轮已出的 48/83 表。
**B1–B3 的整批重审属于「重审」，产出的是新表，适用本节**；R1–R5 已出的 5 张表不追溯修改、仍按当时口径有效。

1. **指示代词作限定词也算依赖**：`these drawings`、`this section`、`such approaches` 这类限定词，若指代对象未在引文内出现，单看引文不知道指谁，判 `DEPENDENT`。判据是「把引文单独贴到综述里，读者是否需要往回翻」。

   > **v1.2 修正（见 §八，优先于本条）**：本句把 `this section` 也算作依赖，已被判例实测推翻——
   > `this paper / this study / this section` 属**篇章自指**，指代对象就是本文本节，读者不需要往回翻，判 `SELF`。
   > 本条仍适用于 `these drawings` / `this approach` / `such approaches` 这类**回指前文具体对象**的限定词。
2. **`SUPPORTED` 只用于分诊，不是合格证**：`SUPPORTED` 条目仍需按 10%–15% 抽检；不得把「SUPPORTED 可自动放行」当作质量结论。

## 八、v1.2 补充口径：自足轴三族边界（2026-11-10，判例实测）

自足轴的口径漂移集中在句首结构上。20 条判例（`CASES_SELF.md`，回写见 `DISPUTED.md` D-02）实测：差异 4 条全部落在
「自指」与「回指」的分界上，且原表对同一构造自身不一致（`this section introduces` 判 `DEP`，而 `This section presents` 判 `SELF`）。
按下列四条执行：

| 族 | 形态 | 判 | 判据 |
|---|---|---|---|
| A 自指 | `this paper / this study / this work / this article / this section / this chapter / the present study` + 谓语 | `SELF` | 指代对象就是本文本节，读者不必往回翻；这里的 `this` 是**篇章自指**，不是回指 |
| B 形式主语 | `It is … that …` / `It should be noted that …`，真主语在 `that` 从句内 | `SELF` | 从句主语与谓语都在引号内 |
| C 回指前文 | `this approach / this method / these limitations / these input graphs / such approaches` 等 + 谓语，先行词不在引文内 | `DEPENDENT` | 把引文单贴出去，读者必须往回翻才知道 `this/these` 指什么 |
| D 片段 | 名词短语、介词短语、`when/while` 从句、分词开头，主谓落在引号外 | `DEPENDENT` | 主语缺失（§五.1 不变） |

边界判据一句话：**`this/these` 后跟篇章名词（paper / study / section）= 自指 → `SELF`；后跟内容名词（approach / limitations / graphs）= 回指 → 看先行词在不在引文内。**

> **影响面已实测，不是估计**：131 条里 A 族 12 条（原表 11 条已判 `SELF`，仅 `B3-11` 判 `DEP`）、B 族 1 条（已判 `SELF`）；
> 按本节点状修正 `B2-05`、`B3-11`（→ `SELF`）与 `R3-12`、`R4-13`（→ `DEPENDENT`）共 4 条后，两轴总量不变
> （`S80/P50/U1 · SELF118/D13`），**不构成「8 张已出表整批重审」的理由**；未落入 A/B/C/D 四族的条目一律不动。
