# Napps2021_BIM_VariantRetrieval_CBR

- 条目 1：论文要解决的问题是在建筑早期设计阶段对建筑设计的变体进行基于 BIM 的检索
  - "This paper outlines a solution for a BIM-based variant retrieval of a building design in early design phases using Case Based Reasoning (CBR) and Pattern Matching (PM)." (Napps, 2021, p.1)
- 条目 2：做匹配与检索的方法是图模式匹配，即从图数据库中按模式查询由案例库选出匹配图
  - "The method of graph pattern matching (GPM) is a possibility to find (suitable) variants from a graph database. Based on a pattern query, matching graphs are selected from a case base that provide an answer to the existing request (problem)." (Napps, 2021, p.3)
- 条目 3：相似度计算落在 IFC 数据结构上，即基于 IFC 标准实现，对 IFC 的 quantity 与 property definition 分别定义相似度度量
  - "According to this approach, the similarities are used for all entities stored in the IFC data structure. Depending on the type of entities, similarity measures can be defined for both IFC quantities and property definitions." (Napps, 2021, p.3)
