# Ayzenshtadt2016_ThinkingWithContainers_ICAART

- 条目 1：系统名称为 MetisCBR，面向建筑设计（architectural design）领域。
  - "In this work we present the distributed retrieval system MetisCBR for the architectural design domain" (Ayzenshtadt et al., 2016, p.1)
- 条目 2：用户的查询建立在 Semantic Fingerprint 这一语义描述模型之上。
  - "user queries built with a semantic description model Semantic Fingerprint" (Ayzenshtadt et al., 2016, p.1)
- 条目 3：agents 以容器化结构组织协作，每个检索容器是嵌套在父级多智能体系统内部的自主子系统。
  - "For the actual building design retrieval step of our approach, we use a container-based structure, where each retrieval container during its activity can be seen as a completely autonomous multi-agent sub-system that is nested inside a parent MAS" (Ayzenshtadt et al., 2016, p.5)
