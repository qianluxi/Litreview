# A2 Maher & Gomez de Silva Garza (1996) — Case-Based Reasoning in Structural Design

- 条目 1：CBR 作为设计过程模型，其作用是把以往已知的设计从记忆中召回，并把设计案例或其子案例改编以适应当前设计情境。
  - "Using CBR as a design process model involves the subtasks of recalling previously known designs from memory and adapting these design cases or subcases to fit the current design context." (Maher, 1996, p.1)
- 条目 2：案例表示的基本做法是用属性—值对来描述案例记忆，这些属性—值对按子系统分组并构成层次，案例记忆的组织与索引都依赖这一层次结构。
  - "At the most basic level, each system uses attribute-value pairs to represent case memory. The attribute-value pairs are grouped into subsystems and form hierarchies, both in case memory organization and in indexing." (Maher, 1996, p.2)
