# Ayzenshtadt2016_ThinkingWithContainers_ICAART

- 条目 1：系统名为 MetisCBR，是一个面向建筑设计领域的分布式检索系统。
  - "In this work we present the distributed retrieval system MetisCBR for the architectural design domain" (Ayzenshtadt et al., 2016, p.1)
- 条目 2：用户的查询建立在名为 Semantic Fingerprint 的语义描述模型之上，代理按容器分组来解析查询。
  - "where agents work in groups (containers) on resolving of user queries built with a semantic description model Semantic Fingerprint" (Ayzenshtadt et al., 2016, p.1)
- 条目 3：每个检索容器在运行期间都是一个嵌套在父级多智能体系统（MAS）内部的完全自治的多智能体子系统。
  - "each retrieval container during its activity can be seen as a completely autonomous multi-agent sub-system that is nested inside a parent MAS" (Ayzenshtadt et al., 2016, p.5)
